# 🏥 Healthcare Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Healthcare Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a visual analysis of healthcare data, including patient information, hospital admissions, medical conditions, admission types, age groups, gender distribution, insurance providers, and billing amounts.

The main objective is to transform healthcare data into meaningful visual insights that can help understand **patient demographics, admission trends, hospital performance, and healthcare billing**.

---

## 🎯 Objectives

- Analyze the total number of patients.
- Monitor healthcare admission trends over the years.
- Analyze admissions across different hospitals.
- Understand patient distribution by age group.
- Compare admissions based on admission type.
- Analyze gender-wise patient distribution.
- Study billing amounts across age groups and medical conditions.
- Filter the dashboard based on admission type and insurance provider.
- Present healthcare information through an easy-to-understand interactive dashboard.

## 📈 Dashboard Features

### 1. Total Patient

A KPI card displays the **total number of patients** available in the dataset.

### 2. Average Age

The dashboard displays the **average age of patients**, providing an overview of the patient population.

### 3. Admissions by Hospital

A bar chart shows the **total admissions for each hospital**.

This helps identify hospitals with higher numbers of patient admissions.

### 4. Admission Trend

A line chart displays the **number of admissions by year**.

This allows users to understand how hospital admissions change over time.

### 5. Age Group Analysis

A pie chart represents **total admissions by age group**.

This helps identify which age groups contribute most to hospital admissions.

### 6. Admission Type Analysis

A pie chart shows the distribution of admissions based on:

- Emergency
- Urgent
- Elective

This provides insight into the different types of hospital admissions.

### 7. Gender-wise Analysis

A clustered column chart compares patient counts by **gender across different years**.

This helps analyze changes in gender-wise patient distribution over time.

### 8. Medical Condition & Age Group

A matrix visual compares **billing amounts** across:

- Age Groups
- Medical Conditions

This provides a detailed view of healthcare billing patterns.

### 9. Admission Type Filter

A slicer allows users to filter the dashboard based on **Admission Type**.

### 10. Insurance Provider Filter

A slicer allows users to analyze the dashboard based on different **Insurance Providers**.
